# ProximiChat — Fabric Voice Chat Mod

Proximity voice chat for Minecraft Java Edition 26.3 with Fabric and Java 25.

## Build

Requires JDK 25. Run `./gradlew build` (Windows: `gradlew.bat build`). The jar is in `build/libs/`.

## Install

Install Fabric Loader and Fabric API for Minecraft 26.3, then install the mod on both client and server.

## Controls

- Push to talk: V
- Toggle mute: M

## Audio

Uses the pure Java Concentus Opus codec. Audio capture requires a working Java Sound microphone input and output device.
